# Eggfarm Client

React + Vite dashboard for the egg farm sales/expense tracker.

See the [root README](../README.md) for the full setup flow. Standalone:
`cp .env.example .env`, `npm install`, `npm run dev` — runs at
`http://localhost:5173` and expects the API (see `server/`) reachable at
the URL in `VITE_API_URL`.
